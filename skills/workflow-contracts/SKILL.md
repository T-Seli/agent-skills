# Workflow contracts

Nothing to run here. The workflow skills read `contracts.md` in this folder before they start. `project-CLAUDE-template.md` is the template for a project's `CLAUDE.md`.

For explicitly delegated local engineering work, optional host-specific profiles
can load the shared skills on demand. See [scoped agents](references/scoped-agents.md)
for selection, connector limits and measurement. Existing workflow routing stays unchanged.
